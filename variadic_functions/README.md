# Variadic Functions

This project introduces variadic functions in C.

## Files

- 0-sum_them_all.c: Returns the sum of all its parameters.
- variadic_functions.h: Contains the function prototypes.

## Requirements

- Ubuntu
- GCC
- Betty coding style
- Betty documentation style

## Function

### sum_them_all

Returns the sum of all the integers passed to the function.

If n is equal to 0, the function returns 0.

- 1-print_numbers.c: Prints a list of integers separated by a string.
