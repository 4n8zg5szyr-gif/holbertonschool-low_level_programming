# argc, argv

This project introduces command line arguments in C.

## Learning Objectives

- Understand how to use arguments passed to a program.
- Understand argc and argv.
- Learn how to retrieve command line arguments.

## Requirements

- Ubuntu 20.04 LTS
- GCC with -Wall -Werror -Wextra -pedantic -std=gnu89
- Betty coding style
- No global variables
- Maximum of 5 functions per file

## Files

- 0-whatsmyname.c: Prints the program name.
