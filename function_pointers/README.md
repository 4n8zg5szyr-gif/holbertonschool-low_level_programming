# Function Pointers

This project introduces function pointers in C.

## Learning Objectives

- Understand what function pointers are.
- Learn how to use function pointers.
- Understand what a function pointer holds.
- Understand where function pointers point in virtual memory.

## Requirements

- Ubuntu 20.04 LTS
- GCC compilation with `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style
- No global variables
- Maximum of 5 functions per file
- Allowed functions: `malloc`, `free` and `exit`

## Files

- `function_pointers.h`: Header file containing function prototypes.
- `0-print_name.c`: Prints a name using a function pointer.
